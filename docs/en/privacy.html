Privacy Policy

Privacy Policy

Better Day Tech ("we") sets out the following policy for handling user information in the iOS app Salon Calendar ("the App").

Summary

  • The App does not send user data to any server we operate.
  • The App does not use accounts, advertising SDKs, analytics SDKs or other third-party SDKs.
  • Schedules, text, selected photos and display settings are stored on the user's device by default.
  • Pro purchases and subscription status checks are processed through Apple's App Store / StoreKit systems.
  • Except when the user explicitly exports or shares content, we do not receive the user's data.

1. Information we collect

We do not collect user information through the App. The App does not include any of the following:

  • Account registration or login
  • Advertising systems or advertising SDKs
  • Usage analytics systems or analytics SDKs
  • Crash collection or other third-party SDKs
  • Mechanisms to collect location information, device identifiers or advertising identifiers

Except when the user explicitly exports or shares content, we do not receive the user's data. Providing content to another person or another app chosen through sharing is an action performed by the user.

2. Information stored on the device

The App stores the following information on the user's device to provide its features:

  • Entered schedule data, including date labels and custom text
  • Text entered as headings, such as salon name or stylist name
  • Images imported as backgrounds
  • Display settings such as typeface, color and layout

This information is deleted from the device when the App is deleted.

3. Photos access

The App uses photo-related features only for the following two purposes:

  • Importing a background photo: The App receives only the photo selected by the user. The App does not read the entire photo library.
  • Saving a created image: When the user chooses to save, the exported image is added to Photos. The App requests permission to add photos for this purpose. It does not request permission to read existing photos.

4. Network communication

The App does not communicate with any server we operate. As stated above, it also does not include third-party SDKs for advertising, analytics or crash collection.

The following are standard functions of the operating system or Apple platform and are separate from sending data to us. They are handled according to Apple's rules:

  • Operation of iOS features such as the photo picker and share sheet
  • Operation of App Store / StoreKit features for Pro subscription purchase, restore, subscription status checks, cancellation and refunds. These are processed by Apple, and purchaser information is not sent to any server we operate
  • Statistics related to App Store distribution, such as download counts, aggregated by Apple. We do not receive information that identifies individual users
  • The App's data may be included in iCloud backups or device backups
  • If the user shares an image to another app or service, handling by that destination

This support site is hosted on GitHub. The App does not automatically connect to the support channel. If the user visits it through a browser or other means, GitHub, Inc.'s rules apply to that visit.

5. Disclosure to third parties

Because we do not collect user information, there is no information for us to disclose to third parties.

6. Children's use

Because the App does not send information to us, it can be used regardless of age. We do not collect personal information from children.

7. User rights

All information stored by the App is on the user's device. The user can edit or delete it in the App, or remove it by deleting the App. Because we do not hold user information, there is no information held by us that can be requested for disclosure, correction or deletion.

8. Changes to this policy

If handling changes because of new features or other updates, we will revise this page and state the revision date. Important changes may also be announced in App update notes.

9. Contact

Questions about this policy are handled through GitHub Issues. Open an issue

Issue posts are public. Please do not include personal information about yourself or anyone else. For privacy or security matters, use the private channel rather than a public issue.

This app is developed and maintained by one person, so we cannot promise individual replies or response timing.
